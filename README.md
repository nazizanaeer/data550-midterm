# Building the Midterm Project Report 

## Project Organization

  - dataset used to build this report is in folder `f75_datasets/`
  - all code to build final report exists in the folder `code/`
  - all outputs derived from the code will be stored in the folder `output/`
  - `Makefile` contains rules for building the final report
  - `renv` package used to add a lock file (`renv.lock`) and folder `renv/` to capture information on packages
  - `config.yml` defines different configurations for customization
  
## Code Description

`code/00_clean_data.R`
  - reads dataset from folder `f75_dataset/`
  - recodes categorical variables as binary or nominal values 
  - saves cleaned dataset as `.rds` objects in the `output/` folder

`code/01_table_one.R`
  - reads cleaned dataset from folder `output/`
  - generates table 1 summarizing baseline and clinical characteristics of children in the treatment and control groups
  - uses median (IQR) for continuous variables and n (%) for categorical variables
  - adds overall and p-value columns for group comparison
  - saves summary table as `output/table1.rds`

`code/02_regression_analysis.R`
  - reads cleaned dataset from folder `output/`
  - runs logistic regression to assess effect of modified f75 on the likelihood of survival
  - generates formatted regression table displaying odds ratios (OR), 95% confidence intervals, and p-values
  - creates a plot
  - saves table as `output/regression_table_config_${WHICH_CONFIG}.rds`

`code/03_render_report.R`
  - renders final project report `midterm_report.Rmd` into `.html` file
  - compiles outputs generated by previous `.R` scripts 
  - saves rendered report as `midterm_report_config_$(WHICH_CONFIG).html` in project directory
  
`Makefile`
This project uses a Makefile to manage the workflow. The main steps are:
  - synchronize the R package library (runs `renv::restore()`)
  - clone the repository
  - install all required R packages using: `make install` (run in Git Bash)
  - if you add or update packages, run `renv::snapshot()` to update the lockfile
  - generate all files (e.g., xx.rds) needed for the midterm report
  - customize the regression analysis by sex using the `WHICH_CONFIG` setting in terminal (`default`, `male`, or `female`)
  - generate the final midterm report (using `make`) based on the regression configuration you choose
